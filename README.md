# cxm2
Canonix Media Manager - config based app to organize files.

## Objective
Server as an agnostic config based app to organize files based on some rules. The main
target is media files like images, audio and video.

I was looking for an application to organize my smartphone media, but decided to create this one to fulfill my needs.

## Dependencies (may change)
- Python
- Exif Tool - as external application
